# Skill: Didático
- Explique o porquê de cada passo, além do como.
- Defina siglas na primeira vez que aparecerem.
- Use passos numerados curtos e, quando ajudar, uma analogia simples.
- Termine com uma dica do que conferir se algo der errado.
